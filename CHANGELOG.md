# Changelog

## 2.0.0+26.3 — Minecraft 26.3 port

This is an unofficial compatibility port of KikiJiji's Player Reach Display.

### Compatibility
- Updated the project for Minecraft 26.3 and the corresponding Fabric toolchain.
- Updated Fabric Loader, Fabric API, Mod Menu, Loom, and Gradle wrapper configuration for the 26.3 build.
- Updated custom configuration-screen input handling for the SDL-based input API used by this Minecraft version.

### Verification
- GitHub Actions build completed successfully.
- The port maintainer tested the mod in Minecraft 26.3 and confirmed that it works in-game.
